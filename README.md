# 🌊 Крым.Гид

**Версия 0.9.2-beta** — туристический помощник по Крыму: **квиз** подберёт
места под ваши интересы и разложит их по дням, **каталог** — 36 проверенных
точек с координатами, **схема-карта** полуострова, **лента** собирает новости
из 5 RSS-лент и 3 телеграм-каналов, **погода** — по 13 курортам.

## Возможности

- **Квиз (7 вопросов)** — интересы, сезон, темп, бюджет, состав, длительность,
  транспорт. На выходе: профиль отдыха, ранжированная подборка мест с
  объяснением «почему», подсказка по логистике и новости, подходящие по интересам.
- **План по дням** — подборка автоматически разложена по дням (2/4/7/12 дней):
  районы сгруппированы (не бегаем через полуостров), слоты утро/день/вечер,
  крупные точки — на целый день, «запасной вариант» на дождливую погоду.
  План можно скопировать **текстом** (в мессенджер) или **ссылкой** — по ссылке
  результат восстанавливается у любого, кто её откроет. На схеме-карте план
  рисуется пронумерованным маршрутом («🗓 Мой план»).
- **Схема-карта** — low-poly SVG-карта полуострова (офлайн, без внешних
  тайлов и ключей): 36 точек с координатами, фильтр по тегам, избранное
  подсвечено, клик — карточка места.
- **Каталог** — фильтры по тегу, географическому району и текст. Карточки с
  сезоном, бюджетом, длительностью и советом; избранное (сердечки) хранится в
  браузере; ссылка на Яндекс.Карты.
- **Погода курортов** — Open-Meteo (без API-ключа), 13 городов, текущее
  состояние + прогноз на 4 дня, кэш на час; если сеть недоступна — виджет
  корректно прячется.
- **Новости** — параллельный опрос **8 источников**: 5 RSS-лент (ТАСС, РБК,
  News.ru, КРИМ-ИНФОРМ, Крым.Цифровой) + **3 телеграм-канала** (публичные
  превью `t.me/s/<канал>` парсятся без API-ключа). Дедупликация,
  классификация по темам (пляжи, погода, транспорт, события, гастро,
  безопасность, история) и фильтр «только про Крым». Кэш 15 минут в памяти +
  **файловый кэш, переживающий рестарт**.
- **Офлайн-режим** — без сети приложение честно показывает бейдж «офлайн»:
  свежие общие заголовки из кэша + демонстрационные крымские материалы
  (помечены во фронтенде).
- **PWA** — приложение устанавливается на телефон/десктоп: манифест,
  иконки и service worker (статика — cache-first, API — network-first
  с откатом в кэш). Без сети открывается оболочка с последними данными.
- **Прямые ссылки на места** — в карточке кнопка «🔗 Поделиться» копирует
  ссылку вида `#/place/<id>`; по ней открывается каталог с модалкой места.
  Отдельный эндпоинт `GET /api/attractions/{id}`.
- **Печать плана** — кнопка «🖨 Печать» в результате квиза (print-стили
  прячут шапку/кнопки, карточки не разрываются между страницами).
- **Сортировка каталога** — по рейтингу, названию (А→Я), времени посещения
  и бюджету; **поиск по новостям** — строка фильтра в ленте.

## Быстрый старт

```bash
./run.sh          # dev: с автоперезагрузкой
./run.sh prod     # prod
```

или вручную:

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Откройте `http://localhost:8000`.

### Docker

```bash
docker build -t crimea-gid .
docker run -p 8000:8000 -v crimea-cache:/srv/cache crimea-gid
```

Контейнер включает healthcheck; кэш новостей вынесен в volume `/srv/cache`.

### CI

GitHub Actions (`.github/workflows/ci.yml`) на каждый push и PR:
тестовый свит (pytest), синтаксис JS и сборка Docker-образа.

## Переменные окружения

| Переменная | По умолчанию | Что управляет |
|---|---|---|
| `PORT` | `8000` | порт сервера |
| `NEWS_CACHE_TTL` | `900` | кэш ленты, сек |
| `NEWS_HTTP_TIMEOUT` | `10` | таймаут запроса к источнику, сек |
| `WEATHER_TTL` | `3600` | кэш погоды, сек |
| `WEATHER_HTTP_TIMEOUT` | `8` | таймаут запроса погоды, сек |

## Тесты

```bash
.venv/bin/pip install pytest
.venv/bin/python -m pytest tests/ -q
```

Модули: `test_recommends.py` (матчинг, планировщик), `test_news.py`
(скоринг «Крым», темы, дедупликация, TTL и файл-кэш, офлайн-fallback),
`test_telegram.py` (парсер t.me/s/), `test_data.py` (схемы данных,
координаты), `test_api.py` (эндпоинты, фильтры, заголовки).

## API

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/health` | Живость + версия |
| GET | `/api/attractions?tag=&area=&q=` | Каталог мест с фильтрами (с lat/lng) |
| GET | `/api/attractions/{id}` | Одна точка каталога + `type_meta` |
| GET | `/sw.js` | Service worker (scope `/`) |
| GET | `/api/areas` | Географические районы полуострова |
| GET | `/api/tags` | Словарь тегов и типов мест |
| GET | `/api/quiz` | Контент квиза |
| POST | `/api/quiz/evaluate` | Ответы квиза → рекомендации + план по дням + новости |
| GET | `/api/news?limit=&refresh=1` | Лента новостей (live / кэш) |
| GET | `/api/weather?city=&refresh=1` | Погода курортов (Open-Meteo) |

## Структура

```
app/
  main.py                  # FastAPI: API + раздача SPA + заголовки безопасности
  config.py                # константы и переменные окружения
  services/
    news.py                # сбор RSS + Telegram, фильтр «Крым», темы, кэш, офлайн
    recommend.py           # матчинг квиз → каталог + планировщик дня
    weather.py             # Open-Meteo, 13 курортов, кэш
    load.py                # загрузка JSON-данных
  data/
    attractions.json       # каталог: 36 мест с координатами
    quiz.json              # вопросы квиза
    sources.json           # источники: RSS (type=rss) и Telegram (type=telegram)
    news_snapshot.json     # офлайн-снимок новостей
static/
  index.html / style.css / app.js   # SPA (vanilla JS, без сборки)
  sw.js / manifest.webmanifest       # PWA: офлайн-оболочка
  img/                               # hero + категорийные изображения + иконки
tests/                             # pytest
.github/workflows/ci.yml           # CI: тесты + JS + docker build
```

## Как расширять

- **Новое место** — объект в `app/data/attractions.json`
  (`id`, `name`, `type`, `region`, `area`, `description`, `tags`, `season`,
  `budget`, `duration_h`, `rating`, `price_hint`, `tips`, `access`,
  `lat`, `lng`). Точка сама появится на карте.
- **Новый RSS-источник** — строка в `app/data/sources.json` с `"type": "rss"`.
- **Новый телеграм-канал** — строка с `"type": "telegram"` и
  `"url": "https://t.me/s/<канал>"` (публичный канал; приватные не работают).
  Неактуальные каналы видны в `failed_sources` ответа `/api/news`.
- **Новый город в погоде** — кортеж в `CITIES` в `app/services/weather.py`.
- **Новый тег** — `TAGS`/`TAG_EMOJI` в `recommend.py` + вариант в `quiz.json`.
- **Темы новостей** — `TOPIC_RULES` в `news.py`.

## Бета: что проверить (checklist для тестировщиков)

1. **Квиз** — 3 сценария: «пляж/пара/лето», «вино/осень/без машины»,
   «с детьми/экономия» — подборка, план по дням, причины.
2. **План** — копирование текстом и ссылкой; открыть ссылку в инкогнито;
   «🖨 Печать» — предпросмотр показывает только план.
3. **Карта** — фильтр по тегам, клик по точке, «🗓 Мой план» после квиза,
   подсветка избранного.
4. **Каталог** — фильтры, поиск, сортировка, избранное (перезагрузка —
   сохраняется), модалки, Яндекс.Карты; «🔗 Поделиться» копирует ссылку
   `#/place/<id>`, открыть её в инкогнито — модалка поверх каталога.
5. **Новости** — статус live/офлайн, темы, «только Крым», поиск по ленте,
   обновление, бейджи источников (RSS и ·TG).
6. **Погода** — виджет на главной (при доступе к Open-Meteo).
7. **Мобильный** — узкая вёрстка, бургер-меню (☰), квиз, карта, модалки.
8. **PWA** — DevTools → Application: манифест виден, service worker
   зарегистрирован; офлайн-режим DevTools — приложение открывается из кэша.

## Известные ограничения (бета)

- Карта — стилизованная схема (low-poly), не географически точная; для
  навигации — ссылка на Яндекс.Карты в карточке.
- Офлайн-снимок крымских новостей — демонстрационные материалы (помечены).
- Телеграм-каналы — публичные превью: последние ~20 постов, без медиа.
- Погода зависит от доступности Open-Meteo из сети пользователя.

## Честность данных

Живые заголовки в `news_snapshot.json` — реальные (ТАСС/РБК/News.ru от
15.09.2026); крымские материалы в офлайн-снимке — **демонстрационные** и явно
помечаются во фронтенде. При наличии сети снапшот не используется.
