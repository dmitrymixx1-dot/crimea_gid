# 🌊 Крым.Гид

Туристический помощник по Крыму: **квиз** подберёт места под ваши интересы,
**каталог** — 36 проверенных точек (дворцы, пляжи, винные погреба, ущелья,
курорты), а **живая лента** собирает новости полуострова из публичных RSS-источников.

## Возможности

- **Квиз (7 вопросов)** — интересы, сезон, темп, бюджет, состав, длительность,
  транспорт. На выходе: профиль отдыха, ранжированная подборка мест с
  объяснением «почему», подсказка по логистике и новости, подходящие по интересам.
- **Каталог** — фильтры по тегу (пляжи, история, вино, гастро, active…),
  географическому району и текстовый поиск; карточки с сезоном, бюджетом,
  длительностью и практическим советом; ссылка на Яндекс.Карты.
- **Новости** — параллельный опрос 5 RSS-лент (ТАСС, РБК, News.ru, КРИМ-ИНФОРМ,
  Крым.Цифровой), дедупликация, классификация по темам (пляжи, погода, транспорт,
  события, гастро, безопасность, история) и фильтр «только про Крым»
  (словарь городов/маркеров полуострова).
- **Офлайн-режим** — если сеть недоступна, приложение честно показывает бейдж
  «офлайн» и отдаёт кэшированный снимок: свежие общие заголовки +
  демонстрационные крымские материалы (помечены во фронтенде).

## Запуск

```bash
./run.sh          # dev: автоперезагрузка при правках
./run.sh prod     # prod: без автоперезагрузки
```

или вручную:

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Откройте `http://localhost:8000`.

## API

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/health` | Живость сервиса |
| GET | `/api/attractions?tag=&area=&q=` | Каталог мест с фильтрами |
| GET | `/api/areas` | Географические районы полуострова |
| GET | `/api/tags` | Словарь тегов и типов мест |
| GET | `/api/quiz` | Контент квиза (вопросы/варианты) |
| POST | `/api/quiz/evaluate` | Ответы квиза → рекомендации + новости |
| GET | `/api/news?limit=&refresh=1` | Лента новостей (live / кэш) |

## Структура

```
app/
  main.py                  # FastAPI: API + раздача SPA
  config.py                # TTL кэша, таймауты, константы
  services/
    news.py                # сбор RSS, фильтр «Крым», темы, офлайн-fallback
    recommend.py           # матчинг квиз → каталог (баллы, причины, профили)
    load.py                # загрузка JSON-данных
  data/
    attractions.json       # каталог: 36 мест с тегами/сезонами/бюджетом
    quiz.json              # вопросы квиза
    sources.json           # RSS-источники
    news_snapshot.json     # офлайн-снимок новостей
static/
  index.html / style.css / app.js   # SPA (vanilla JS, без сборки)
  img/                               # изображения (hero + категории)
```

## Как расширять

- **Новое место** — добавьте объект в `app/data/attractions.json`
  (`id`, `name`, `type`, `region`, `area`, `description`, `tags`, `season`,
  `budget`, `duration_h`, `rating`, `price_hint`, `tips`, `access`).
- **Новый источник новостей** — допишите строку в `app/data/sources.json`.
- **Новый тег** — добавьте его в `TAGS` и `TAG_EMOJI` в `app/services/recommend.py`,
  вариант в `app/data/quiz.json` и используйте в `tags` мест.
- **Правила тем новостей** — `TOPIC_RULES` в `app/services/news.py`
  (регулярки по заголовкам/аннотациям).

## Честность данных

Живые заголовки в `news_snapshot.json` — реальные (ТASS/РБК/News.ru от 15.09.2026);
крымские материалы в офлайн-снимке — **демонстрационные** и явно помечаются
во фронтенде. При наличии сети снапшот не используется вообще.
