# Схемы данных

Весь контент приложения — JSON-файлы в `app/data/`. Они читаются через
`app/services/load.py` с `lru_cache` (файл читается один раз за процесс).
Ниже — контракты, которым данные обязаны соответствовать; большинство
проверяется тестами (`tests/test_data.py`).

## attractions.json

Каталог мест. Массив объектов:

| Поле | Тип | Обязательно | Ограничения | Описание |
|---|---|---|---|---|
| `id` | string | ✔ | уникальный, slug (`a-z`, `-`), без пробелов | ключ для URL `#/place/<id>`, избранного |
| `name` | string | ✔ | | название места |
| `type` | string | ✔ | ключ `TYPE_META` | тип точки (см. [справочники](#справочники)) |
| `region` | string | ✔ | ≥3 символов | локация для подзаголовка («Ялта → Ай-Петри») |
| `area` | string | ✔ | ключ `AREA_LABEL` | географический район (кластер планировщика) |
| `description` | string | ✔ | | 1–3 предложения для карточки |
| `tags` | string[] | ✔ | ⊆ `TAGS`, непусто | теги матчера |
| `season` | string[] | ✔ | ⊆ `{spring, summer, autumn, winter}` | лучшие сезоны |
| `budget` | int | ✔ | 1–3 | 1 — эконом … 3 — премиум |
| `duration_h` | number | ✔ | 0 < x ≤ 12 | сколько часов закладывать; ≥6 — «на целый день» |
| `rating` | number | ✔ | 0–5 | популярность (лёгкий бонус в балле) |
| `price_hint` | string | ✔ | | «вход ~300 ₽», «бесплатно» |
| `tips` | string | ✔ | | практический совет для модалки |
| `access` | string | ✔ | `car` `transit` `both` | доступность без машины |
| `lat` | float | ✔ | 44.0–45.6 | широта (точка на схеме-карте) |
| `lng` | float | ✔ | 33.0–37.0 | долгота |

Минимальный пример:

```json
{
  "id": "new-place",
  "name": "Новое место",
  "type": "nature",
  "region": "Судак, окрестности",
  "area": "Восточный",
  "description": "Короткое описание для карточки.",
  "tags": ["nature", "photo"],
  "season": ["spring", "autumn"],
  "budget": 1,
  "duration_h": 3,
  "rating": 4.5,
  "price_hint": "бесплатно",
  "tips": "Вода и удобная обувь обязательны.",
  "access": "car",
  "lat": 44.95,
  "lng": 35.1
}
```

После добавления объекта точка сама появится в API, каталоге, квизе
и на схеме-карте. Прогоните `pytest tests/test_data.py` — он проверит
все ограничения из таблицы выше.

## quiz.json

Контент квиза: объект с `intro` и массивом `questions` (ровно 7).

| Поле | Тип | Ограничения | Описание |
|---|---|---|---|
| `id` | string | см. ниже | `purpose` `season` `tempo` `budget` `party` `duration` `transport` |
| `type` | string | `multi` / `single` | мультивыбор только у `purpose` |
| `max` | int | только у `multi` | максимум выбранных вариантов |
| `emoji` | string | | иконка вопроса |
| `title` / `subtitle` | string | | текст вопроса / подсказка |
| `options[]` | object[] | id уникальны вопросе | варианты ответа |

Опция: `{ "id": "beach", "emoji": "🏖️", "label": "Море и пляжи", "hint": "…" }`
(`hint` необязателен).

Согласованность с кодом (проверяют тесты):

- опции `purpose` ⊆ ключей `TAGS`;
- опции `duration` ⊆ ключей `DAYS_BY_DURATION` и `ITINERARY_DAYS`;
- каждый тег `TAGS` доступен как опция первого вопроса `purpose`;
- профиль отдыха `PROFILES[tag]` существует для любого выбранного интереса;
- связь интереса с темами ленты `PURPOSE_TOPICS[tag]` задана для каждого тега.

## sources.json

Источники новостей. Массив объектов:

| Поле | Тип | Ограничения | Описание |
|---|---|---|---|
| `id` | string | уникальный | попадёт в `items[].source_id` |
| `name` | string | | показывается в `items[].source` и `failed_sources` |
| `url` | string | http(s), уникальный | RSS/XML-лента или `https://t.me/s/<канал>` |
| `type` | string | `rss` / `telegram` | выбирает парсер |
| `description` | string | | комментарий для редакторов |

Для `telegram` важно: работают только **публичные** каналы (превью
`t.me/s/…`, последние ~20 постов, без медиа). Недоступные источники не
роняют ленту — попадают в `failed_sources`.

## news_snapshot.json

Офлайн-снапшот: показывается, когда недоступны все источники.

```json
{
  "fetched_at": "2026-09-15T12:00:00+03:00",
  "items": [
    {
      "title": "…", "link": "https://…", "source": "ТАСС",
      "published": "2026-09-15T…", "summary": "…", "sample": true
    }
  ]
}
```

Требуется: непустой `items`; у каждого элемента — `title`, `link`,
`source`. Флаг `sample: true` помечает демонстрационные материалы
(фронтенд показывает дисклеймер). Темы (`topics`) снапшоту досчитывает
сервер при выдаче.

## Формат элемента новости (API)

То, что получает фронт после `_normalize()`:

| Поле | Тип | Описание |
|---|---|---|
| `id` | string | `n<N>` — живая лента, `s<N>` — снапшот |
| `title` | string | ≤200 символов, без HTML |
| `link` | string | URL материала |
| `summary` | string | ≤300 символов, без HTML |
| `published` | string | ISO 8601 или исходная строка даты |
| `source` / `source_id` | string | имя и id источника |
| `crimea_score` | int | 0 — не про Крым; чем больше, тем «крымче» |
| `topics` | string[] | до 3 тем |

## Справочники

**Теги (`TAGS`, 15 шт.)**: `beach` пляжи · `nature` природа ·
`history` история · `culture` дворцы и музеи · `food` гастрономия ·
`wine` вино · `active` активный отдых · `extreme` экстрим и дайвинг ·
`family` с детьми · `photo` фотогении · `spa` спа и грязели ·
`city` набережные и города · `view` панорамы · `free` бесплатно ·
`romance` для двоих. Все 15 тегов доступны в первом вопросе квиза `purpose`,
имеют профиль в `PROFILES` и маппинг на темы новостей в `PURPOSE_TOPICS`.

**Типы (`TYPE_META`)**: `beach` Пляж · `castle` Крепость · `palace` Дворец ·
`winery` Вина · `nature` Природа · `park` Парк · `city` Город ·
`spa` Спа · `food` Гастро · `museum` Музей · `active` Активный ·
`factory` Детям. У каждого — `emoji`, `label`, `img` (файл в `static/img/`,
существование проверяет тест).

**Районы (`AREA_LABEL`)**: `Южный берег`, `Центральный`, `Восточный`,
`Западный`.

**Слоты плана**: `morning` утро · `afternoon` день · `evening` вечер ·
`full` целый день.

**Темы новостей**: `safety` ✋ безопасность · `transport` транспорт ·
`beach` пляжи · `weather` погода · `nature` природа · `events` события ·
`food` гастро · `history` история.
