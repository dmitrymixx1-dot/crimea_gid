## Краткая карта проекта

```
┌────────────┐   HTTP/JSON   ┌─────────────────────────────────┐
│  SPA (vanilla JS, hash-роутер, PWA) │  FastAPI: app/main.py    │
│  static/   │ ◄───────────► │  ├─ services/recommend.py (квиз) │
│            │               │  ├─ services/news.py (RSS+TG)    │
│            │               │  ├─ services/weather.py (погода) │
│            │               │  ├─ services/marine.py (море)    │
│            │               │  └─ services/load.py (данные)    │
└────────────┘               └─────────────────────────────────┘
        ▲                              ▲
   service worker               app/data/*.json (каталог, квиз,
   (офлайн-оболочка)            источники, офлайн-снапшот)
```

- **Бэкенд** — Python 3.11+, FastAPI, без базы данных: весь контент —
  читаемые человеком JSON в `app/data/`.
- **Фронтенд** — SPA на чистом JS без сборки и зависимостей
  (`static/app.js`, hash-роутинг `#/...`).
- **Внешние сервисы** — только публичные: RSS-ленты, превью
  телеграм-каналов (`t.me/s/…`), Open-Meteo (без ключей).
